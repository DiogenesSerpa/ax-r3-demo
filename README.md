# Demonstração criptografada de AX R3

Este repositório contém somente a página de acesso e um pacote criptografado. O código legível e os documentos são mantidos em repositório privado.

Não há credenciais de acesso neste repositório. O conteúdo usa AES-256-GCM, chave derivada com PBKDF2-SHA256 e sal e IV aleatórios.
